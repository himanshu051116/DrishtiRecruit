# DrishtiRecruit v0.6 demo flow

## Goal
Demonstrate that DrishtiRecruit is now a complete evidence-coverage ATS rather than an isolated AI scoring feature.

1. Open the Northstar public careers page and show the Backend Engineer role.
2. Sign in as recruiter and open Priya. Show high Fit but incomplete Evidence/Decision Coverage.
3. Queue a candidate message from the application page; show it in candidate notifications/outbox.
4. Approve a Docker verification and open the standardized assessment. Show MCQ/practical/coding/SQL/debugging-capable UI.
5. Open Assessment Analytics and explain completion/score/tab-switch signals. State clearly that tab switching is a review signal, not automatic misconduct.
6. Schedule an unresolved-criterion interview and download the `.ics` calendar invite.
7. Compare Priya vs Arjun: Priya has higher apparent fit while Arjun has stronger evidence coverage.
8. Export the recruiter CSV report.
9. Sign in as Admin and demonstrate audited account deactivation/reactivation.
10. End on DecisionTrace: evidence state -> system readiness -> human decision.
